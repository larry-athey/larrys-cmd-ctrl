# LCC Slave PCB (type 1)

This is the LCC Slave printed circuit board for everything other than a stepper motor controller. As you can see, this is just the power supply and carrier for the ESP32-S3, everything else is an external peripheral that plugs into the main PCB. Note the pin orientation of the ESP32-S3, it is surface mounted (or edge soldered) on the bottom side of the PCB so the board will fit in an HO scale locomotive with the brains isolated from heat generated by the motor.
