# About 3D Models

If you want to 3D print a case for your Orange Pi Zero 3, I will provide links to 2 different ones rather than bothering with designing my own from scratch. Why reinvent the wheel?

- Mission Control Server: https://www.printables.com/model/542569-orange-pi-zero-3-case

- Sound Server: https://www.printables.com/model/572566-orange-pi-zero-3-case-with-expansion-board

## Cube Speaker Models

If you are using a Sound Server with an LCC controlled model railroad, this will be the most common speaker enclosure used on the top side of the track bed. This enclosure requires a Dayton Audio DMA58-8 or DMA58-4 full range 2" speaker and a matching 2" passive radiator.
